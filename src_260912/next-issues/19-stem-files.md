## 목표

분리된 스템 오디오 파일 네 개를 각각 올려 동기 재생하고, 각 트랙의 레벨을 따로 잰다.

## 배경

**원본 프로토타입에 이미 있는 기능이다.** 다른 「이후 과제」 넷과 성격이 다르다. 나머지는 원본에도 없던 신규 설계이지만, 이것은 원본에 있는데 이번 재구현에서 아직 옮기지 않은 자리다.

원본 `resona.html` 의 02 스템 패널에 `대역 의사분리` 와 `4트랙 스템` 두 모드가 있고, `loadStemFile(idx, file)` 로 슬롯마다 파일을 받는다. 안내 문구까지 있다.

> **의사분리** — 스테레오 mid/side와 대역·트랜지언트로 4채널을 추정합니다. 실제 분리가 필요하면 **4트랙 스템**으로 전환 후 Demucs로 뽑은 drums/bass/vocals/other 파일을 각 슬롯에 넣으세요 (샘플레이트·길이 동일 필수).

지금 구현은 의사분리만 있다. 새로 설계하지 말고 원본을 옮겨라.

## 작업

- [ ] 02 스템 패널에 모드 전환 (`대역 의사분리` ↔ `4트랙 스템`)
- [ ] 슬롯 네 개에 각각 파일 받기. 슬롯을 누르면 파일 선택이 열린다
- [ ] 네 파일을 하나의 `AudioContext` 에서 동기 재생한다
- [ ] 트랙별 RMS 측정과 음소거 토글
- [ ] 스템을 쓰지 않을 때는 지금의 추정 스템으로 되돌아간다
- [ ] 길이나 샘플레이트가 다른 파일을 넣으면 사유를 알린다

## 완료 기준

- [ ] 스템 네 개를 올리면 각 트랙의 레벨 미터가 독립적으로 움직인다
- [ ] 보컬 트랙을 음소거하면 그 채널만 0 이 되고 나머지는 그대로다
- [ ] 직조 씬의 세로실 굵기가 실제 스템값을 따라간다 (추정값일 때와 눈에 띄게 다르다)
- [ ] 모드를 의사분리로 되돌리면 파일 없이도 이전처럼 동작한다
- [ ] 재생 위치를 옮겨도 네 트랙이 어긋나지 않는다

## 주의

**동기가 이 기능의 전부다.** 네 파일을 각각 재생하면 몇 밀리초씩 밀린다. 하나의 컨텍스트에서 같은 시각에 걸어야 한다. 밀리면 스템값이 서로 어긋나 직조 씬의 매듭 위치가 흔들린다.

**우선순위가 낮은 이유를 알고 시작해라.** 스템 파일을 미리 뽑아 두는 일은 Demucs 같은 도구를 따로 돌려야 하고, 공연 당일에 곡이 바뀌면 쓸 수 없다. 의사분리는 어떤 곡이든 그 자리에서 돈다. 실제 무대에서 더 자주 쓰이는 것은 의사분리 쪽이다.
