## 목표

곡의 구간 전환을 감지해 음악 상태 판정을 개선한다. 후렴에 들어가는 순간을 화면이 한 박 먼저 알아채게 한다.

## 배경

원본 프로토타입에도 없고 지금 구현에도 없다. 상태 판정(`MusicState`)을 RMS 와 플럭스만으로 하고 있어서, 소리가 커지는 것은 알아도 **구조가 바뀌는 것**은 놓친다. 후렴은 대개 진입 직전에 한 마디쯤 비워 두는데, 그 구간에서 RMS 가 떨어지므로 지금 판정은 오히려 힘을 뺀다.

## 작업

- [ ] `lib/audio/novelty.ts` — 최근 N 프레임의 스펙트럼 평균과 현재 스펙트럼의 코사인 거리
- [ ] 노벨티 값을 `MusicAnalysis` 에 더한다 (0~1 정규화)
- [ ] `lib/direction/state.ts` 의 상태 판정에 반영한다
- [ ] `lib/direction/mood.ts` 의 `arousal` 시상수를 노벨티가 높을 때 짧게 잡는다
- [ ] 09 분석 리드아웃에 노벨티 값을 표시한다
- [ ] 외부 연동 채널에 `/resona/novelty` 를 더한다 (`02-features.md` F-802 표도 함께 고친다)

## 방법

**자기유사도 행렬을 쓰지 마라.** 정확하지만 무겁고, 이 콘솔은 공연 중에 프레임을 지켜야 한다. 가벼운 근사를 먼저 시도한다.

```
ref  = 최근 N 프레임의 스펙트럼 평균
nov  = 1 - cos(ref, 지금 스펙트럼)
```

N 과 정규화 범위는 정해 두지 않았다. 화면을 보며 정하고, **정한 값을 `05-signal-processing.md` 9절에 되돌려 적어라.** 다음 사람이 같은 자리에서 다시 헤매지 않게 한다.

## 완료 기준

- [ ] 후렴이 뚜렷한 곡에서 후렴 진입 지점에 노벨티가 솟는다
- [ ] 같은 구간이 반복되는 동안에는 낮게 유지된다
- [ ] 팔레트 자동이 켜져 있을 때 후렴에서 색이 이전보다 빨리 움직인다
- [ ] 노벨티를 0 으로 고정해도 기존 동작이 그대로 성립한다. 없어도 되는 값이어야 한다
- [ ] fps 가 떨어지지 않는다

## 주의

**없어도 지금 구조는 성립한다.** 이 값이 상태 판정을 전부 대체하지 않는다. RMS·플럭스 판정에 얹는 보조 신호다. 노벨티 하나로 상태를 정하게 만들면 조용한 곡에서 상태가 널뛴다.

정규화가 까다로운 값이다. 곡마다 스펙트럼의 변화 폭이 달라서, 절댓값으로 임계를 걸면 어떤 곡에서는 늘 켜지고 어떤 곡에서는 한 번도 안 켜진다. 관객 보정과 같은 방식으로 최근 구간의 분포를 쓰는 편이 낫다.
