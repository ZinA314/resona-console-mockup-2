## 목표

관객 에너지를 0~1 값 하나로 뽑는다.

## 배경

관객 입력 방식은 공연장 사정에 따라 달라진다. 카메라를 못 쓰는 곳도 있고 객석 마이크가 없는 곳도 있다. 그래서 두 방식이 같은 인터페이스를 구현하게 만들고, 설정 한 줄로 바꿀 수 있게 한다.

시뮬레이션부터 만드는 이유는, 카메라 없이도 이후 개발을 진행할 수 있어야 하기 때문이다.

## 작업

- [ ] `lib/audience/types.ts` 에 `AudienceSource` 인터페이스
- [ ] 시뮬레이션 구현 (느린 기저 에너지 + 128 BPM 맥동 + 수동 슬라이더)
- [ ] 카메라 구현: 64×36 격자 축소, 휘도 변환, 전역 밝기 변화 제거, 잡음 바닥값 0.012, 칸 평활 0.30
- [ ] 자동 보정: 최근 1800 샘플, 5·95 퍼센타일, 15 샘플마다 갱신, 600 샘플에서 완료 표시
- [ ] 어택 1.5초 / 릴리스 3.0초 비대칭 평활
- [ ] 상태 구간 판정 (DORMANT / STIRRING / ACTIVE / SURGE)
- [ ] 04 관객 패널 전체: 방식 선택, 미리보기, 큰 숫자, 24칸 LED, 보정 표시, 재보정 버튼, 영향력 슬라이더
- [ ] `NO FRAMES STORED` 고정 문구
- [ ] 관객 씬
- [ ] 상단 바 관객 값 표시
- [ ] R 키로 보정 초기화

## 완료 기준

- [ ] 카메라 앞에서 움직이면 값이 오른다
- [ ] **조명을 껐다 켜도 급등하지 않는다** (전역 밝기 변화 제거가 되는지)
- [ ] 20초 뒤 보정 완료가 뜬다
- [ ] 박수가 끝나도 값이 천천히 내려간다 (릴리스가 어택보다 길어야 한다)
- [ ] 권한을 거부해도 다른 기능이 계속 동작한다
- [ ] 카메라 프레임이 서버로 나가지 않는다 (네트워크 탭 확인)

## 주의

원본 프레임을 저장하거나 전송하지 않는다. 격자로 줄인 즉시 버린다. 개인 식별과 얼굴 인식은 하지 않는다.
