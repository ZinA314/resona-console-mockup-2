## 목표

캔버스를 세우고 음악이 화면을 움직이게 한다.

## 작업

- [ ] `components/stage/Stage.tsx`: 캔버스 컨테이너, `devicePixelRatio` 반영, 리사이즈 대응
- [ ] 프레임 루프 구현 (`docs/04-flows.md` 4절 순서대로)
- [ ] 스펙트럼 씬 (진단용이라 먼저 만들면 편하다)
- [ ] 직조 씬 — `docs/03-screens.md` 4절의 직조 항목을 그대로 구현한다. 가로실만 쌓으면 안 되고 다음 네 층을 순서대로 그려야 한다
  - [ ] 가로실(위사) — 흔들리는 곡선, 최근 행 강조, 오래된 행 감쇠
  - [ ] 세로실(경사) — 스템별 굵기(`WGT`)와 색
  - [ ] 매듭 — 스템값 0.58 초과 지점의 사각 표식
  - [ ] 평직 교차 — 행마다 어긋나는 짧은 덧실
  - [ ] 행 높이를 그 순간의 세기에 비례시키기 (균등 간격 아님)
  - [ ] 교차점 사인파 흔들림 (사인 두 개 + 최근 세 행의 추가 흔들림)
- [ ] 공통 효과: 잔상, 입자, 교란, 비트 테두리
- [ ] 06 씬 패널과 숫자키 1~5 전환 (무대 씬 `6` 은 `12-stage-bloom.md` 에서 더한다)
- [ ] 출력 창 분리 (`window.open` + `BroadcastChannel`)
- [ ] 블랙아웃(B), 전체 화면(F), 출력 창 열기(O) 단축키

## 완료 기준

- [ ] **가로실과 세로실이 교차해 천처럼 보인다.** 가로줄만 쌓이면 통과가 아니다
- [ ] 실이 직선이 아니라 물결친다
- [ ] 음악이 센 구간의 행이 넓게, 약한 구간이 촘촘하게 남는다
- [ ] 드럼이 세게 나온 자리에 매듭이 찍힌다
- [ ] 재생하면 줄이 비트마다 쌓인다
- [ ] **왼쪽 셀비지에 마디 번호가 연속으로 찍힌다** (`008 009 010 011` 처럼). 마디를 색으로 강조하지 않는다 — 원본에 없는 동작이다
- [ ] 스펙트럼 씬에서 6밴드 경계 눈금이 보인다
- [ ] 출력 창을 두 번째 화면으로 옮겨도 같이 움직인다
- [ ] B 키를 누르면 즉시 검게 되고 다시 누르면 돌아온다
- [ ] 60fps 를 유지한다
