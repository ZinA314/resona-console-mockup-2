## 목표

가사 파일이 없는 곡도 그 자리에서 큐를 만들 수 있게 한다.

## 배경

가사 파일을 미리 만들어 오지 못한 곡이 리허설에 올라온다. 원본 프로토타입에는 LRC 를 직접 입력하고 재생하면서 타임스탬프를 찍는 편집기가 있었는데, 우리 명세에서 빠져 있었다. 실제로 쓰이는 기능이라 채운다.

## 작업

- [ ] 03 가사 패널을 `표시` / `편집` 두 탭으로 나눈다
- [ ] 원문 입력 영역 — LRC 원문 또는 타임스탬프 없는 순수 가사
- [ ] `파싱` — `[mm:ss.xx]` 가 붙은 줄만 큐로
- [ ] `길이에 균등 배분` — 타임스탬프 없는 줄을 곡 길이에 고르게 나눠 출발점을 만든다
- [ ] **`탭 모드`** — 켜면 `Space` 가 "현재 줄에 지금 시각 찍기" 로 바뀌고 찍을 때마다 다음 줄로 내려간다
- [ ] 탭 모드 배너 — 화면 상단에 붉게 `탭 모드 — Space 는 타임스탬프 찍기 · ESC 로 나가기`
- [ ] 줄 목록 — 타임스탬프 직접 수정, 줄 클릭으로 그 시각 탐색, 재생 중 현재 줄 강조
- [ ] 전체 오프셋 `−0.1s` `+0.1s`
- [ ] `LRC 내보내기` — `.lrc` 파일 다운로드
- [ ] `저장` — Supabase `lyrics` 에 곡과 묶어 저장

## 완료 기준

- [ ] 타임스탬프 없는 가사를 붙여 넣고 균등 배분하면 줄이 곡 전체에 퍼진다
- [ ] 탭 모드로 스무 줄을 찍은 뒤 모드를 끄면 그 타임스탬프대로 가사가 넘어간다
- [ ] **탭 모드를 끄면 `Space` 가 다시 재생과 일시정지로 돌아온다**
- [ ] 탭 모드가 켜져 있는 동안 배너가 보인다
- [ ] `ESC` 로 탭 모드에서 빠져나온다
- [ ] 내보낸 `.lrc` 를 다시 올리면 같은 큐가 된다
- [ ] 전체 오프셋을 두 번 누르면 가사가 0.2초 밀린다

## 구현 주의

**배너는 선택 사항이 아니다.** `Space` 는 평소 재생과 일시정지에 쓰는 키다. 배너 없이 뜻을 바꾸면 공연 중에 재생을 멈추려다 가사를 망가뜨린다. 탭 모드에 들어가고 나가는 것이 화면에서 항상 보여야 한다.

키 처리는 한곳에 모은다. 전역 단축키 처리기에서 탭 모드 여부를 먼저 확인하고 갈라야, 편집기 컴포넌트와 전역 처리기가 같은 키를 두 번 처리하는 일이 없다.
