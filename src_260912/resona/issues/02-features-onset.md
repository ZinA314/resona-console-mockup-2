## 목표

주파수 특징을 뽑고 온셋을 검출한다. BPM 은 다음 이슈에서 다룬다.

## 배경

2단계 전체를 한 번에 만들면 BPM 이 틀렸을 때 원인이 특징 추출인지 템포 추정인지 구분되지 않는다. 그래서 두 이슈로 나눈다. 이 이슈가 끝나면 BPM 을 뺀 모든 수치가 화면에 뜬다.

## 작업

- [ ] mid / side 신호 분석 — 신호 영역에서 (L+R)×0.5, (L-R)×0.5 를 만든 뒤 각각 FFT. 크기 스펙트럼끼리 빼지 않습니다
- [ ] 스펙트럴 플럭스: 증가분만 누적, `flux = Σ max(0, mid - prevMid) / N × 42`
- [ ] 부분 플럭스 두 개: `fluxHi`(HI·AIR 구간), `fluxKick`(SUB·LOW 구간)
- [ ] 6밴드 에너지 (SUB 20-60 / LOW 60-250 / LMID 250-500 / MID 500-2000 / HI 2000-6000 / AIR 6000-16000)
- [ ] 스펙트럴 센트로이드
- [ ] 피크 감쇠 추적 (계수 0.985)
- [ ] 의사 스템 추정 4종 + 채널별 AGC
- [ ] 온셋 검출: 적응 임계값 `중앙값(55퍼센타일) × 1.5 + 0.022`, 최소 간격 85ms, RMS 하한 0.035
- [ ] 09 분석 리드아웃 패널에 모든 값 표시 (4프레임마다 갱신)
- [ ] 온셋 발생 시 화면에 시각적 표시

## 완료 기준

- [ ] 6밴드 값이 SUB 부터 AIR 까지 모두 움직인다
- [ ] 스템 네 칸이 서로 다르게 움직인다
- [ ] 온셋이 드럼 소리와 함께 깜빡인다
- [ ] 무음 구간에서 온셋이 발생하지 않는다
- [ ] 60fps 를 유지한다
