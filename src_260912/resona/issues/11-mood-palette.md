## 목표

곡의 성격을 두 실수로 재고, 그 값으로 화면 색을 자동으로 정한다.

## 배경

5단계-A 까지 오면 음악과 관객이 결합해 연출 파라미터가 나온다. 그런데 그 파라미터에는 "지금 얼마나 센가" 만 있고 "이 곡이 어떤 곡인가" 가 없다. 발라드의 후렴과 댄스곡의 후렴은 둘 다 `PEAK` 으로 판정되지만 같은 화면이면 안 된다.

두 축을 새로 만든다.

| 축 | 뜻 | 무엇을 정하는가 |
|---|---|---|
| `valence` | 밝음 ↔ 어두움 | 색 — 어떤 팔레트를 쓸지 |
| `arousal` | 격렬함 ↔ 잔잔함 | 결 — 화면이 몽환적일지 날카로울지 |

이 두 줄이 이 이슈의 전부다. 색은 밝기에서 오고, 결은 격렬함에서 온다.

## 작업

### 크로마와 분위기

- [ ] `lib/audio/chroma.ts`: 크로마 12빈 (100~2000Hz, 평활 계수 0.90, 8프레임에 한 번)
- [ ] Krumhansl-Schmuckler 프로파일로 장·단 근사, `majorness` 와 `chromaConf` 산출
- [ ] `lib/direction/mood.ts`: `valence` (시상수 6초), `arousal` (시상수 3초)
- [ ] 신뢰도가 낮을 때 해당 항의 비중을 줄이고 남은 몫을 비례 배분
- [ ] 분위기 다섯 이름 판정, 최소 8초 유지와 경계 여유 0.06
- [ ] 몽환도 `dreaminess` 산출. 관객 gain 은 음수 −0.35

### 팔레트

- [ ] `lib/palette/builtin.ts`: 기본 팔레트 여덟 (색값은 명세 8-2절 표 그대로)
- [ ] `lib/palette/oklab.ts`: sRGB ↔ OKLab 변환과 보간
- [ ] `lib/palette/resolve.ts`: 가장 가까운 앵커 두 개를 역거리로 섞고, 시상수 2.5초로 따라가기
- [ ] **자동 후보 기본값은 네 모서리뿐.** `MONO` `심해` `노을` `설야` 는 `auto: false` 로 시작
- [ ] 새 파일을 로드해도 색 보간기를 비우지 않는다 (분위기 판정만 비운다)
- [ ] **자동과 수동을 배타로.** 색 추종 강도 슬라이더를 없앤다 (섞을 대상이 없다)
- [ ] 자동이 켜져 있으면 어느 카드에도 선택 표시가 없다
- [ ] 카드를 누르면 자동이 꺼지고 그 카드가 선택된다
- [ ] `자동` 을 토글로 끄면 직전 섞임의 우세 팔레트가 선택된다
- [ ] `palettes` 테이블과 RLS 정책. 기본 팔레트는 `builtin` 으로 모두가 읽고, 고치면 사본 생성

### 화면

- [ ] 05 팔레트 패널: 자동 스위치, 전환 시간
- [ ] 분위기 2축 평면 위젯 — 현재 점, 최근 30초 자취, 팔레트 앵커. **앵커를 끌어서 옮길 수 있어야 한다**
- [ ] 팔레트 카드 목록, `자동 후보` 토글, 새로 만들기·복제·삭제
- [ ] 컬러칩 편집기 — 역할 다섯, 색상환, HEX 입력, 최근 색 스와치
- [ ] 08 연출 파라미터 패널에 `몽환도` 추가 (두 층의 방향이 반대인 것 표시)
- [ ] **패널 번호를 배치 순서에 맞게 다시 매긴다** — 왼쪽 01~05, 오른쪽 06~11
- [ ] 기존 씬들이 HEX 대신 팔레트 역할 다섯 개로 색을 내도록 개편
- [ ] `P` 키로 자동 켜기/끄기, `[` `]` 로 팔레트 이동

## 완료 기준

- [ ] 밝은 팝을 걸면 노랑 계열, 단조 발라드를 걸면 남색 계열이 잡힌다
- [ ] **섞임 표시에 `MONO` 가 뜨지 않는다.** 뜬다면 자동 후보에서 빼지 않은 것이다
- [ ] 밝은 곡의 무대색이 탁한 회갈색이 아니다
- [ ] 곡을 바꿀 때 색이 즉시 튀지 않고 2~3초에 걸쳐 넘어간다
- [ ] 자동을 끄면 고른 팔레트에 그대로 머문다
- [ ] 컬러칩을 고치면 즉시 화면에 반영된다. 저장을 기다리지 않는다
- [ ] 팔레트를 `MONO` 로 두고 직조 씬을 보면 원본과 같은 흑백에 빨강 강조 화면이 나온다
- [ ] 2축 평면에서 앵커를 옮기면 같은 곡에서 다른 팔레트가 뽑힌다
- [ ] 관객 에너지를 올려도 색은 바뀌지 않는다
- [ ] 드럼만 나오는 구간에서 `valence` 가 급락하지 않는다

## 검증

**네 모서리 음원으로 확인한다.** 각각 40초이고, 명세 7-3·7-4절의 산식을 거꾸로 읽어 만들었다.

| 파일 | 겨냥한 분위기 | 예측 밝기 / 격렬함 |
|---|---|---|
| `synth/test-06-mood-deep.wav` | 침잠 DEEP | 0.00 / 0.29 |
| `synth/test-07-mood-serene.wav` | 평온 SERENE | 0.91 / 0.12 |
| `synth/test-08-mood-fervent.wav` | 격정 FERVENT | 0.35 / 0.67 |
| `synth/test-09-mood-radiant.wav` | 희망 RADIANT | 0.95 / 0.65 |

예측값은 명세 산식을 따로 구현해 낸 것이라 화면 값과 절대값이 다를 수 있다. **네 파일이 서로 갈리는지**를 본다.

`synth/test-10-mood-sweep.wav` (75초)는 네 모서리를 20초씩 지나간다. 값이 아니라 **색 전환**을 보는 파일이다. 색이 한 프레임에 튀지 않고 2~3초에 걸쳐 넘어가는지, 분위기 평면의 점이 네 모서리를 도는지 확인한다.

`music/knockout.mp3` 로 실제 음악에서도 도는지 확인한다.

`synth/test-03-buildup.wav` 로 `arousal` 이 곡 진행을 따라 오르는지 본다.

## 구현 주의

**이름으로 분기하지 않는다.** 분위기 다섯 이름은 팔레트 앵커와 화면 표시에만 쓰고, 실제 연출은 `(valence, arousal)` 두 실수를 직접 쓴다. 이름으로 씬을 만들면 경계를 넘는 순간 화면이 끊긴다.

**색은 반드시 OKLab 에서 섞는다.** sRGB 를 그대로 보간하면 파랑과 노랑 사이가 탁한 회색을 지나간다.

**관객은 색에 손대지 않는다.** 팔레트 선택에도 색 보간에도 관객 값이 들어가면 안 된다.
