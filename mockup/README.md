## 무대 = LED 4면 (2026-11-02 수정)
가로 960 × 세로 960 정사각 LED **4장을 나란히 붙인** 3840×960 출력. PGM 마스터는 1920×480(4:1)이고 한 장 = 480×480 패널 → 3D 무대의 LED 1~4에 그대로 대응. **우측 LED 거울상 제거**(콘솔·무대 양쪽) — 4장 모두 PGM을 이어서 보여줍니다. 무대 분위기(트러스·조명·객석·골목 세트)는 기존 유지. 상단 `LED GUIDE`로 PGM 위에 면 경계·번호 표시. team2 무대의 `레조나 출력`도 LED 1~4 네 줄(각 960×960)로 바뀜.

## 자막 모션 (왼쪽 03 → `모션`, 단축키 `S`)
| 모드 | 내용 |
|---|---|
| BASIC | 한 번 뿌려지는 방식: `한번에 표시`(아래서 살짝 올라오며 등장) · `카라오케 채움` · `글자 순차` |
| SCAN TYPE | DIA Scan Type 방식의 슬릿스캔. 스캔선 뒤쪽이 줄무늬로 끌려 번짐 |

SCAN 설정: DIRECTION(↔/↕) · SPEED · ROTATION · SLICES · INTENSITY · EASE · REPEAT X/Y · RANDOM D(방향)/T(시간) · SEED — 여기까지는 원본과 같은 항목.
RESONA 전용 추가: **SETTLE**(줄이 진행될수록 번짐이 풀려 읽힘) · **REACT**(음량·박자에 스캔 속도 반응) · AREA(하단 띠 / 화면 전체) · COLOR · TEXT(비우면 가사, 입력하면 그 글자 고정).
섹션별로 덮어쓰기: 오른쪽 08 `자막 모션` (상속 / BASIC / SCAN). 예: 코러스만 SCAN.
**BESPOKE STACK**(마지막 씬 기본값, 구간별로도 지정): DIA *Bespoke* 처럼 굵기가 다른 세로 열마다 같은 글자를 줄줄이 쌓고 바깥 굵은 열은 가장자리에서 잘림(왼쪽은 끝, 오른쪽은 처음). 설정 COLUMNS · ROWS · CROP · DRIFT · REACT · BG · INVERT, 가사가 바뀌면 위→아래로 줄 교체. `마지막 씬` 토글로 끄기.
원본은 GPU 셰이더이고 이 목업은 캔버스 2D로 같은 원리를 구현한 것이라 모양은 비슷하되 동일하지 않습니다.

## Roto-Control (노브 8 × 2뱅크 · 패드 16 · LCD)
노브 뱅크 **A · FX** = 선택 섹션의 JITTER · PUNCH · HUE · BLUR · GRAIN · STROBE · SPEED · LIGHT.
노브 뱅크 **B · LED 4** = LED 1~4 밝기 · SHIFT(좌우 이동) · ZOOM · SPLIT(0 = 4면 이어짐 / 100 = 장마다 같은 화면) · FADE. 값은 구간마다 저장. 섹션이 바뀌면 모터가 저장값으로 이동.
패드 = S1~S8 섹션 점프(PAD 뱅크로 S9~S16) / ▶ / ◀SEC / SEC▶ / MENT / LYRIC / CAM / MODE / BLK.
MIDI(가정값): CC1~8 = 현재 뱅크 노브, 노트 36~51 = 패드, 노트 52 = 노브 뱅크, 53 = 패드 뱅크, **Program Change n = 송출 시트 n 호출**.

## 여분 분절 · CUE SHEET (오른쪽 05 · 10)
- `+ 여분 분절`: 선택 구간을 재생헤드(없으면 가운데)에서 둘로 나눔 → 새 구간(SPARE, 부모 값 복사). `− 합치기`: 앞 구간에 합침. 라벨 변경 시 해당 라벨 기본 룩 재적용. 구간이 늘면 패드 뱅크(S9~S16)로 호출.
- `CUE SHEET`: 구간마다 **송출 시트 번호**(0~127) 지정, 겹치면 빨간 표시. 번호로 이동(GO SHEET) · MIDI Program Change · CSV 내보내기(Q · 시트 · 구간 · 시간 · 클립). *송출 시트 = 큐 시트 번호로 해석한 값 — 다른 뜻이면 알려주세요.*

## 미디어 추가 (왼쪽 02 · 오른쪽 06)
- 02 `+ 미디어 추가` 또는 파일(영상·이미지, 여러 개)을 목록에 끌어놓기 → `CLIP(5)`, `CLIP(6)`… 슬롯이 자동 생성. 06에서는 같은 목록에서 고르고, `+ 이 구간에 파일 넣기`는 새 슬롯을 만들어 선택한 구간에 바로 배정.
- 슬롯 칩의 작은 버튼: ✎ 이름 변경(새 슬롯) · **4면 복제 / 이어붙임 / 맞춤**(화면 방식) · ↻/1×(루프) · ✕ 삭제(기본 클립은 생성 영상으로 되돌리기).
- **기본 = 복제·맞춤**: 어떤 크기의 파일이든 **긴 쪽 기준으로 LED 칸(960×960) 안에 전부 들어가게**(남는 곳은 검정) LED 1~4에 같은 화면으로 복제. 확대·지터 같은 효과도 LED 칸마다 따로 적용돼 영상이 경계를 넘지 않고 4면이 완전히 같게 움직임.
- 슬롯 칩의 방식 버튼(누를 때마다 순환): `복제·맞춤` → `복제·채움`(칸을 꽉 채워 자름) → `이어·맞춤`(4:1 한 장, 긴 쪽 기준) → `이어·채움`.
- **LED별 영상** (06 아래): 선택한 구간에서 LED 1~4마다 슬롯을 따로 고르거나 `+ 파일`로 바로 넣으면 그 LED만 별도 영상으로 바뀜(비우면 구간 클립을 따름). `모든 구간에 적용` · `개별 해제`. 구간별로 저장되고 새로고침 후에도 유지.
- **새로고침해도 유지** (이 브라우저 안에만): 파일은 IndexedDB, 편집값은 localStorage. 저장 대상 = 구간 편집(클립·LED별 영상·노브 A/B와 on/off·조명·카메라·구간 자막 모션·라벨·여분 분절·송출 시트 번호)과 `T` 탭으로 맞춘 가사 시각. 구간 편집은 **분석 소스(구간 구조)마다 따로** 저장되어 `실행 결과` ↔ `사전 분석`을 오가도 각각 남음. 새로고침하면 `실행 결과`로 열리므로 다른 소스는 버튼을 누르거나 JSON을 다시 불러오면 복원. 왼쪽 패널의 전역 설정(자막 모션·폰트·카메라 모드 등)은 저장하지 않음.
- `전체 초기화` 버튼: 넣은 미디어, 구간 편집, 가사 시각을 모두 지우고 처음 상태로 복귀.
- 재생 중인 클립과 다음 클립만 영상을 돌려 부담을 줄임.

## OUTPUT · REC (오른쪽 11, 상단 ● REC)
브라우저 Capture API(MediaRecorder)로 **LED 1~4 출력(노브 뱅크 B 적용 후)** 을 3840×960 또는 1920×480 .webm 으로 녹화 → 정지하면 자동 저장. `재생 시작과 함께 녹화 · 곡 끝나면 자동 저장` 옵션. 오디오는 `file://` 로 열면 보안상 빠질 수 있어 `python3 build/range_server.py` 로 연 주소에서 권장. 탭이 백그라운드면 프레임이 멈춤.
화면 안 가상 장비로 시연. 실물은 상단 `ROTO-CONTROL` → Web MIDI(크롬). **MIDI 매핑(CC1~8, 노트 36~51)은 가정값**이며 실물 확인 후 확정.
